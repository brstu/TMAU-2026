## 2. Математические модели варианта

| Модель | Тип | Уравнение |
|---|---|---|
| Model 1.8 | Линейная дискретная модель (AR) | $y_{\tau+1} = a_1 y_\tau + a_2 y_{\tau-1} + b_1 u_\tau + b_2 u_{\tau-1}$ |
| Model 2.10 | Нелинейная модель (Tanh) | $y_{\tau+1} = a \cdot \tanh(y_\tau) + b \cdot u_\tau^3$ |

## 3. Анализ устойчивости Model 1.8

Для анализа устойчивости рассматривается свободный процесс, то есть $u_\tau = 0$:
$y_{\tau+1} = a_1 y_\tau + a_2 y_{\tau-1}$.

Применяя Z-преобразование, получаем характеристическое уравнение:
$z^2 - a_1 z - a_2 = 0$.

Корни находятся по формуле: $z_{1,2} = \frac{a_1 \pm \sqrt{a_1^2 + 4 a_2}}{2}$.

Дискретная линейная модель асимптотически устойчива, если **оба** корня строго лежат внутри единичной окружности: $|z| < 1$. Граничный случай $|z| = 1$ не считается асимптотической устойчивостью. Анализатор отклоняет не конечные коэффициенты (`NaN`, бесконечность). Перед запуском симуляции Model 1.8 программа выводит найденные корни и предупреждение, если модель неустойчива.
