Detailed Description

Линейная модель 1.8 — обобщённая авторегрессионная: y[t+1] = a1*y[t] + a2*y[t-1] + b1*u[t] + b2*u[t-1].

Начальные условия: y[0] = y_start, y[-1] = 0, u[-1] = 0.
