Detailed Description

Нелинейная модель 2.2 — с насыщением исполнительного механизма: y[t+1] = a*y[t] + b*sat(u[t]), sat(u) = u_max при u > u_max; u при u_min <= u <= u_max; u_min при u < u_min.
