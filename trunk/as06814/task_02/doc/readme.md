## Анализ устойчивости линейной модели (Model 1.4)

Дискретная модель 1.4 задается разностным уравнением:
$$y_{\tau+1} = a y_{\tau} + b (u_{\tau} - u_{\tau-1})$$

Характеристическое уравнение системы:
$$z - a = 0 \implies z = a$$

### Критерий устойчивости на Z-плоскости:
Система является **устойчивой**, если корень лежит внутри единичного круга:
$$|z| = |a| < 1$$

- При $|a| < 1$ переходный процесс является сходящимся (устойчивым).
- При $|a| \ge 1$ процесс расходится (система неустойчива).

В модуле `StabilityAnalyzer` реализована проверка `checkAndWarnStability(a)`, которая перед началом симуляции генерирует предупреждение в консоль, если выбранное значение $a$ приводит к неустойчивому процессу.

## Структура проведенных тестов

1. **Тесты модуля устойчивости (`test_stability.cpp`)**:
   - Верификация граничных значений $|z| = 1$ ($a = 1.0$, $a = -1.0$).
   - Проверка устойчивых режимов ($|a| < 1$).
   - Проверка неустойчивых режимов ($|a| > 1$).
   - Точность определения корней характеристического уравнения.
2. **Параметризованные тесты (`test_models_param.cpp`)**:
   - Использование `TEST_P` для верификации численных значений шагов симуляции без дублирования кода.
   - Проверка физических инвариантов (нулевой вход $u=0$ при $y=0$ дает $y=0$).
   - Сравнение интегрирования по методу Эйлера (`Model 3.2`) с точным аналитическим решением.
3. **Mock-тестирование сигналов (`test_mock_signal.cpp`)**:
   - Подмена входных воздействий с помощью **Google Mock** (`ISignalProvider`).
   - Проверка управления при ступенчатом, импульсном и гармоническом воздействиях.
