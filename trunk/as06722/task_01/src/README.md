# [task_01] Юреня ЛР1

Лабораторная работа №1 по дисциплине «Теория и моделирование автоматического управления».

Проект содержит C++17/CMake-приложение для моделирования трёх моделей. Результаты сохраняются в `results.csv`, после чего программа автоматически запускает `src/plot.py`, сохраняет изображение графика в каталог `doc` и открывает окно Matplotlib.

## Запуск в Windows

Дважды щёлкните `build_and_run.bat`. Скрипт:

1. проверит наличие CMake и Python launcher `py`;
2. заново сконфигурирует проект;
3. соберёт `task01.exe`;
4. запустит программу;
5. после расчёта график откроется автоматически.

Для визуализации требуется Matplotlib:

```bat
py -m pip install matplotlib
```

Подробный отчёт находится в `doc/readme.md`, UML-диаграмма — в `doc/uml.puml`.
