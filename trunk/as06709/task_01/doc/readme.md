# Лабораторная работа №1 — вариант 17

## Цель работы
Разработать программу на C++ для моделирования трёх математических моделей выбранного варианта с применением ООП, вводом параметров пользователем, табличным выводом и автоматической визуализацией.

## Модели варианта 17

### Линейная модель 1.7
\[
y_{\tau+1}=ay_\tau+b_1u_\tau+b_2u_{\tau-1}+b_3u_{\tau-2}.
\]
Пользователь вводит коэффициенты `a`, `b1`, `b2`, `b3`.

### Нелинейная модель 2.1
\[
y_{\tau+1}=ay_\tau-by_{\tau-1}^{2}+cu_\tau+d\sin(u_{\tau-1}).
\]
Пользователь вводит коэффициенты `a`, `b`, `c`, `d`.

### Дифференциальная модель 3.5
\[
\frac{dy}{dt}=b\sin(u),\qquad
y_{\tau+1}=y_\tau+\Delta t\,b\sin(u_\tau).
\]
Применяется явный метод Эйлера. Пользователь вводит `b` и `dt`.

## Выбор режима и входные воздействия
За один запуск пользователь выбирает **одну** из трёх моделей и **одно** входное воздействие. Программа не рассчитывает все модели и сигналы автоматически.

- Ступенчатое: `u(tau) = const`; значение `const` вводит пользователь.
- Импульсное: `u(0)=1`, при `tau > 0` значение равно нулю.
- Гармоническое: `u(tau)=sin(tau)`.

Также пользователь вводит число шагов `n` (от 1 до 10000). Для каждой новой симуляции состояние модели начинается с нуля.

## Результаты и визуализация
Результаты выбранного эксперимента выводятся в консоль в таблице с колонками `tau`, `u(tau)`, `y(tau+1)` и записываются в `src/results.csv`. После завершения расчёта BAT-файл автоматически запускает `plot_results.py`: открывается окно Matplotlib с графиками входного сигнала и выходной реакции. Изображение дополнительно сохраняется как `src/plot_results.png`.

Для визуализации необходимы Python и Matplotlib:
```bash
python -m pip install matplotlib
```

## ООП и структура классов
`Model` — абстрактный базовый класс. Виртуальный метод `calculateNext` реализуется в классах `LinearModel17`, `NonlinearModel21`, `DifferentialModel35`. Общий метод `step` вызывает переопределённый расчёт и обновляет историю состояния и входа. Это обеспечивает наследование и полиморфизм.

## Дополнительное задание: устойчивость
Для однородной части Model 1.7:
\[
y_{\tau+1}=ay_\tau,\qquad z-a=0.
\]
Корень характеристического уравнения: `z=a`. Условие асимптотической устойчивости: `|a|<1`. Программа проверяет введённый пользователем коэффициент `a` и предупреждает, если `|a| >= 1`. Это проверка однородной части линейной модели.
