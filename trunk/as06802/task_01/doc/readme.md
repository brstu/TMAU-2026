## 1. Цель работы

Изучить методы моделирования дискретных динамических систем, реализовать три модели (1.7, 2.1, 3.5) в виде объектно-ориентированной программы на C++, провести симуляцию при трёх типах входного сигнала (ступенчатый, импульсный, гармонический) и проанализировать поведение систем.

---

## 2. Исходные данные варианта

### 2.1. Модель 1.7 — линейная рекуррентная система 2-го порядка

Уравнение: $$y_{t+1} = a \, y_t + b_1 \, u_t + b_2 \, u_{t-1} + b_3 \, u_{t-2}$$

Параметры: $a = 0.8$, $b_1 = 0.5$, $b_2 = 0.2$, $b_3 = 0.1$.

Условие устойчивости: $|a| < 1$. Для $a = 0.8$ условие выполняется — система устойчива.

### 2.2. Модель 2.1 — нелинейная система 2-го порядка

Уравнение: $$y_{t+1} = a \, y_t - b \, y_{t-1}^{2} + c \, u_t + d \, \sin(u_{t-1})$$

Параметры: $a = 0.7$, $b = 0.1$, $c = 1.0$, $d = 0.5$

Нелинейность вносит вклад в виде квадрата предыдущего выхода и синуса предыдущего входа.

### 2.3. Модель 3.5 — непрерывная система, решённая методом Эйлера

Дифференциальное уравнение: $$\frac{dy}{dt} = b \, \sin(u)$$

Дискретизация (метод Эйлера): $$y_{t+1} = y_t + \Delta t \, b \, \sin(u_t)$$

Параметры: $b = 1.5$, $\Delta t = 0.1$
---

## 3. Описание реализации

Программа построена по объектно-ориентированному принципу:

- **Базовый абстрактный класс `Model`** (`Model.h`): содержит чисто виртуальные методы `step(double u)` — один шаг расчёта, и `reset()` — сброс состояния.
- **Производные классы** (`Models.h`): `Model1_7`, `Model2_1`, `Model3_5` — реализуют конкретные уравнения и хранят внутреннее состояние (y, y_prev, u1, u2, u_prev).
- **`main.cpp`**: создаёт три модели, прогоняет их последовательно при трёх типах входного сигнала на n = 30 шагах с шагом dt = 0.1, результаты пишет в CSV-файлы `output_Step.csv`, `output_Impulse.csv`, `output_Harmonic.csv` и дублирует в консоль.
- **Проверка устойчивости модели 1.7** реализована в `main.cpp`: при |a| >= 1 выводится предупреждение `WARNING: Model 1.7 UNSTABLE!`. Для варианта 17 (a = 0.8) предупреждение не появляется.
- **Визуализация** — скрипт `plot.py` на Python (pandas + matplotlib) строит графики по CSV и сохраняет их в `doc/plot_<тип>.png`.
- **Сборка** — CMake (`CMakeLists.txt`, стандарт C++17) и скрипт `run_build.bat` для Windows.

### 3.1. Типы входных сигналов

- Ступенчатый (Step): $u_t = 1$ для всех $t$
- Импульсный (Impulse): $u_t = 1$ при $t = 0$, иначе $u_t = 0$
- Гармонический (Harmonic): $u_t = \sin(t \, \Delta t)$

## 5. Результаты моделирования

Симуляция выполнена на 30 шагах. Для каждого типа входа строились графики переходных процессов (файлы `doc/plot_Step.png`, `doc/plot_Impulse.png`, `doc/plot_Harmonic.png`).

### 5.1. Ступенчатый вход

- **Model 1.7**: выход монотонно стремится к установившемуся значению $$y_{\infty} = \frac{b_1 + b_2 + b_3}{1 - a} = \frac{0.5 + 0.2 + 0.1}{1 - 0.8} = 4.0$$. 
Процесс апериодический, без колебаний, время установления ~15–20 шагов.
- **Model 2.1**: выход выходит на установившееся значение с учётом нелинейных членов; за счёт $-b \, y_{t-1}^{2}$ рост замедляется, устанавливается конечное значение.
- **Model 3.5**: выход линейно растёт $$y_t \approx \Delta t \, b \, \sin(1) \, t = 0.1 \cdot 1.5 \cdot \sin(1) \cdot t \approx 0.126 \, t,$$ при постоянном входе — интегратор.

### 5.2. Импульсный вход

- **Model 1.7**: импульс «затухает» по закону $$y_t \approx b_1 \, a^{t-1}$$ (плюс вклад b2, b3 на первых шагах) — быстрое экспоненциальное затухание благодаря a = 0.8.
- **Model 2.1**: отклик затухает, но нелинейность искажает форму по сравнению с линейной системой.
- **Model 3.5**: после импульса u = 0, sin(0) = 0, поэтому выход «замирает» на достигнутом значении (эффект запоминания).

### 5.3. Гармонический вход

- **Model 1.7**: линейная система отрабатывает гармонику с фазовым сдвигом и усилением/ослаблением амплитуды (частотная характеристика).
- **Model 2.1**: из-за нелинейностей появляются искажения — форма выхода не строго синусоидальна.
- **Model 3.5**: выход — интеграл от $\sin(\sin(t \, \Delta t))$, форма более сложная, с накоплением.

---

## 6. Анализ устойчивости

Для **Model 1.7** корень характеристического уравнения $z = a = 0.8$, $|z| < 1$ — система **устойчива**, что подтверждается графиками: при ступеньке выход ограничен (4.0), при импульсе затухает, при гармонике — ограниченные колебания.

Для **Model 2.1** и **Model 3.5** строгий анализ устойчивости в линейном смысле неприменим (нелинейность и интегратор соответственно). Однако при заданных параметрах и ограниченном входе выходы остаются ограниченными на всём интервале моделирования (30 шагов), что говорит об отсутствии расходимости.
