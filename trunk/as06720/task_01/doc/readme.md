# Вариант 15

В работе исследуется реакция трёх моделей объекта управления на типовые
входные сигналы. По таблице вариантов для варианта 15 назначены:
линейная модель **1.5**, нелинейная модель **2.9** и дифференциальное
уравнение **3.3**. Программа написана на C++17, собирается CMake,
графики строит скрипт на Python (Matplotlib).

## 1. Постановка задачи

### 1.1. Модель 1.5 — запаздывание по состоянию

Выход на следующем шаге зависит от текущего выхода и от выхода,
запомненного $k$ шагов назад:

$$y_{\tau+1} = a_1 y_{\tau} + a_2 y_{\tau-k} + b u_{\tau}, \quad k \ge 1$$

Чтобы получить $y_{\tau-k}$, класс `Model1_5` держит очередь `std::deque`
из $k+1$ последних значений выхода.

### 1.2. Модель 2.9 — корневая модуляция управления

Вход проходит через нелинейность «корень из модуля со знаком»:

$$y_{\tau+1} = a y_{\tau} + b \sqrt{|u_{\tau}|} \cdot \text{sign}(u_{\tau})$$

Малые по модулю сигналы при этом усиливаются, а большие — ослабляются.

### 1.3. Модель 3.3 — апериодическое звено первого порядка

Непрерывное уравнение

$$\frac{dy}{dt} = -a y + b u$$

переводится в разностную форму явным методом Эйлера с шагом $\Delta t$:

$$y_{\tau+1} = y_{\tau} + \Delta t \, (-a y_{\tau} + b u_{\tau})$$

### 1.4. Тестовые воздействия

- ступенька: $u_{\tau} = 1$ для всех $\tau$;
- импульс: $u_0 = 1$, далее $u_{\tau} = 0$;
- гармоника: $u_{\tau} = \sin(\tau)$.

### 2.3. Работа с программой

После запуска программа спрашивает число шагов $n$ (от 1 до 1000),
модель (одну или все три), входной сигнал (один или все три) и
коэффициенты выбранных моделей. Нажатие Enter оставляет значение,
указанное в квадратных скобках. Перед расчётом выводится результат
проверки устойчивости. Каждая пара «модель — сигнал» печатается
в консоль таблицей и сохраняется в `doc/<модель>_<сигнал>.csv`.

Значения по умолчанию:

- модель 1.5: $a_1 = 0.5$, $a_2 = 0.3$, $b = 1$, $k = 2$;
- модель 2.9: $a = 0.7$, $b = 1$;
- модель 3.3: $a = 1$, $b = 1$, $\Delta t = 0.1$;
- число шагов $n = 30$.

### 2.4. Сборка

в папку `build`, собирает его с подробным выводом, запускает программу
и вызывает `src/plot.py`.

## 3. Проверка устойчивости (Advanced Level)

**Модель 1.5.** Однородное уравнение
$y_{\tau+1} = a_1 y_{\tau} + a_2 y_{\tau-k}$ после Z-преобразования
и умножения на $z^{k}$ даёт характеристический многочлен степени $k+1$:

$$z^{k+1} - a_1 z^{k} - a_2 = 0$$

Процесс сходится, только если модули всех корней меньше единицы.
Корни ищутся численно методом Дюрана–Кернера; если наибольший модуль
$\ge 1$, программа печатает предупреждение. Для быстрой оценки удобно
помнить, что условие $|a_1| + |a_2| < 1$ гарантирует устойчивость,
а $a_1 + a_2 < 1$ необходимо для неё.

При значениях по умолчанию уравнение $z^3 - 0.5z^2 - 0.3 = 0$ имеет
$\max|z| \approx 0.884$, т.е. модель устойчива, а установившийся выход
на ступеньку равен $b / (1 - a_1 - a_2) = 5$.

**Модель 2.9.** Нелинейность действует только на вход, поэтому
устойчивость определяется корнем $z = a$: нужно $|a| < 1$.
На ступеньку выход стремится к $b / (1 - a) \approx 3.33$.

**Модель 3.3.** У схемы Эйлера один корень $z = 1 - a\Delta t$,
условие $|1 - a\Delta t| < 1$ равносильно $0 < a\Delta t < 2$.
На ступеньку выход стремится к $b / a = 1$.

Так выглядит предупреждение при $a_1 = 1.2$, $a_2 = 0.5$, $k = 3$:

## 5. Выводы

- Запаздывание в модели 1.5 делает переходный процесс немонотонным:
  после импульса через $k$ шагов на графике появляется повторный подъём,
  а на ступеньку выход медленно подходит к значению 5.
- В модели 2.9 при $|u| = 1$ нелинейность незаметна, но на синусоиде
  малые значения входа усиливаются, поэтому амплитуда выхода больше,
  чем у аналогичного линейного звена.
- Модель 3.3 сглаживает вход: на ступеньку выход экспоненциально
  растёт до 1, а синусоида проходит с заметным ослаблением и сдвигом
  по фазе, как через фильтр низких частот.
- Проверка устойчивости позволяет заранее увидеть, что выбранные
  коэффициенты приведут к расходящемуся процессу.
